Requires CDFER's KiCAD library (https://github.com/CDFER/JLCPCB-Kicad-Library) and the custom symbol and footprint libraries in Component models/KiCAD_symbol_ library. 

Contains version with bare ESP32-S3R8 chip and version with ESP32-WROOM-1 module. Only major difference is bare chip version features RTC clock and uses strapping pin GPIO46 for ILI9341 DC line. This should work but has to be tested.
